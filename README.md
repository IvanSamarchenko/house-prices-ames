# Предсказание цены домов (Ames Housing)

Регрессионная модель, которая предсказывает цену продажи дома по 79 признакам (площади, качество отделки, возраст, район и др.). Данные: соревнование [House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques) на Kaggle (1460 обучающих записей).

Итоговое решение — ансамбль из 7 моделей (`StackingRegressor`) с подбором гиперпараметров через Optuna. Метрика: RMSE на логарифме цены.

## Результаты

| Вариант | RMSE (log), кросс-валидация |
|---|---|
| Ridge | 0.1277 ± 0.0139 |
| RandomForest | 0.1405 ± 0.0158 |
| Базовый стек (Ridge, RandomForest, CatBoost) | 0.1216 ± 0.0128 |
| CatBoost (лучшая одиночная модель) | 0.1197 ± 0.0121 |
| **Итоговый стек (7 моделей)** | **0.1185 ± 0.0126** |

Метрика посчитана как среднее ± стандартное отклонение по фолдам. Фолды для итоговой оценки отличаются от тех, что использовались при подборе гиперпараметров. Преимущество стека над CatBoost невелико и сопоставимо с разбросом между фолдами.

## Что сделано

- **Предобработка.** Пропуски заполнены с учётом их смысла (`"None"` или 0 там, где объекта нет, остальные заполнены модой обучающей выборки). Годы постройки и реконструкции заменены на длительности и флаг реконструкции, добавлены бинарные флаги отсутствия объектов (подвал, гараж, камин и др.).
- **Исследовательский анализ.** Оценены распределения, скошенность и дисбаланс категорий. Подробный отчёт: [report.html](report.html).
- **Преобразование признаков.** Логарифмирование скошенных признаков (`log1p`), масштабирование и one-hot кодирование внутри `Pipeline`, чтобы исключить утечку данных. Целевая переменная обучается в логарифмической шкале.
- **Модели.** ElasticNet, SVR, LightGBM, RandomForest, CatBoost и две нейросети Keras (с одним и двумя скрытыми слоями).
- **Подбор гиперпараметров.** Optuna (сэмплер TPE, MedianPruner, история в SQLite). Для линейных моделей и SVR дополнительно подбираются параметры удаления выбросов и объединения редких категорий.
- **Ансамбль.** `StackingRegressor`, метамодель — Ridge с неотрицательными весами. Основной вклад дают CatBoost, LightGBM и SVR.

## Как запустить

1. Клонируйте репозиторий и установите зависимости (рекомендуется Python 3.11):
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   cd ИМЯ_РЕПОЗИТОРИЯ
   pip install -r requirements.txt
   ```
2. Скачайте `train.csv` и `test.csv` со [страницы соревнования](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) и положите их в папку `datasets/`.
3. Откройте `Main_notebook.ipynb` и выполните ячейки сверху вниз.

Поиск гиперпараметров в ноутбуке закомментирован и занимает много времени. Для воспроизведения результатов он не нужен: лучшие параметры загружаются из файлов `best_*.json`. Чтобы запустить поиск заново, раскомментируйте соответствующие ячейки.
